# Archived — superseded publication direction

Archived 2026-09-18. These are the "full multimodal system" paper drafts (the 3-stage
wearable+image pipeline, written up as one document) and their supporting slide decks.

**Why archived**: the publication strategy changed. Instead of one paper describing the
whole assembled pipeline, the first paper is now a systematic architecture comparison for
the image model (Stage B) — screening lightweight CNN candidates before committing to one
for the hardware build — with the same comparison methodology to be repeated for the
wearable/sensor side (Stage A) afterward. See
`../../honors-paper-report.docx` for the new direction.

Nothing here is deleted or wrong — the underlying experiments (WESAD calibration, Stage B
shortcut audit, cross-dataset generalization, sleep trigger negative result) are all still
real, still documented in `docs/`, and still usable as source material for future papers.
This drafted document just isn't the shape of the first paper anymore.
